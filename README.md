# jalil-M.github.io

Personal site: https://jalil-m.github.io

Dark, particle background, links to LinkedIn and GitHub. Plain HTML/CSS/JS, no build step.

## Structure

```
index.html
css/style.css
js/particles.js
assets/favicon.png
```

## Local dev

Just open `index.html`, or serve the folder:

```
python3 -m http.server
```

## Deploy

Pushes to `master` publish via GitHub Pages.
